## 1. 굿노트 설계 요약
- 각 신호등의 전체 주기(G+Y+R)를 구하고, 모든 주기의 최소공배수(LCM)를 탐색 상한(max_time)으로 설정함.
- 신호등별 상태를 'g'*g + 'y'*y + 'r'*r 문자열 패턴으로 미리 생성한 뒤, 0초부터 max_time-1초까지 순회하며 t % period 인덱스가 모두 'y'인 최초 시각(t+1)을 반환함.

## 2. 필기 vs 실제 코드 오차 분석 (Gap Analysis)
- 굿노트 손필기 생략 (코드 직구현 풀이)
- 시각이 1초부터 시작하므로 0-based 인덱스(t)로 탐색 후 t + 1을 반환해야 하며, 전체 주기의 LCM 이내에 해가 없으면 이후 패턴이 반복되므로 -1을 반환함.

## 3. Python 실전 개선 팁
- Python 3.9 이상에서는 반복문으로 gcd를 직접 계산하는 대신 math.lcm(*(g + y + r for g, y, r in signals))로 최소공배수를 한 줄에 구할 수 있음.
- 문자열 패턴을 생성하지 않고 수학적 구간 판별(g <= t % p < g + y)을 사용하면 공간 복잡도를 O(1)로 줄일 수 있음.

## 4. 최종 통과 코드 (Python)
```python
import math


def solution(signals):
    periods = []
    patterns = []
    max_time = 1

    for g, y, r in signals:
        p = g + y + r
        periods.append(p)
        patterns.append('g' * g + 'y' * y + 'r' * r)
        # 모든 신호등 주기의 최소공배수 계산
        max_time = (max_time * p) // math.gcd(max_time, p)

    for t in range(max_time):
        all_yellow = True
        for i in range(len(signals)):
            if patterns[i][t % periods[i]] != 'y':
                all_yellow = False
                break

        if all_yellow:
            return t + 1

    return -1
```
