## 1. 굿노트 설계 요약
- 문자열 각 인덱스가 몇 번째 스포 방지 구간에 속하는지 spoiler_idx 배열(-1은 일반 구간)에 미리 매핑함.
- 문자열을 순회하며 단어의 인덱스 범위 내 최대 구간 번호를 구해, -1이면 일반 단어 집합(plain_words)에 저장하고, 0 이상이면 해당 구간이 열릴 때 완전히 공개되는 단어 목록(revealed_at)에 왼쪽 순서대로 추가함.
- 스포 방지 구간을 0번부터 순서대로 열면서 일반 단어와 중복 공개 단어를 제외하고 중요한 단어 수를 카운트함.

## 2. 필기 vs 실제 코드 오차 분석 (Gap Analysis)
- 굿노트 손필기 생략 (코드 직구현 풀이)
- 한 단어가 여러 스포 방지 구간에 걸칠 수 있으므로, 단어 내 문자들이 속한 구간 번호의 최댓값(max)을 해당 단어의 최종 공개 시점으로 잡아야 함.

## 3. Python 실전 개선 팁
- 단순 split()을 쓰면 단어의 원본 시작·끝 인덱스를 잃어버리므로, 투 포인터(while 루프)로 인덱스를 직접 추출하는 것이 안전함.
- 일반 단어(plain_words)와 이미 센 단어(seen)를 list가 아닌 set으로 관리해야 조회 시간복잡도를 O(1)로 유지할 수 있음.

## 4. 최종 통과 코드 (Python)
```python
def solution(message, spoiler_ranges):
    n = len(message)
    spoiler_idx = [-1] * n
    for idx, (s, e) in enumerate(spoiler_ranges):
        for i in range(s, e + 1):
            spoiler_idx[i] = idx

    plain_words = set()
    revealed_at = [[] for _ in range(len(spoiler_ranges))]

    i = 0
    while i < n:
        if message[i] == ' ':
            i += 1
            continue
        start = i
        while i < n and message[i] != ' ':
            i += 1
        word = message[start:i]
        last_range = max(spoiler_idx[start:i])
        if last_range == -1:
            plain_words.add(word)
        else:
            revealed_at[last_range].append(word)

    answer = 0
    seen = set()
    for words in revealed_at:
        for word in words:
            if word not in plain_words and word not in seen:
                answer += 1
                seen.add(word)

    return answer
```
